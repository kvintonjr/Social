# Social Media Post Generator

This is a simple system that generates social media posts based on trends. The output is saved to a local `posts.csv` file.

## How to Use

1.  **Prerequisites:** Make sure you have Python 3 installed on your system.
2.  **Run the script:** Open a terminal or command prompt, navigate to the project directory, and run the following command:
    ```bash
    python run.py
    ```
3.  **Check the output:** After running the script, a file named `posts.csv` will be created (or updated if it already exists) in the same directory. This file will contain the generated social media post. Each time you run the script, a new row will be added to this file.

## Project Structure

-   `run.py`: The main script that generates the post and saves it to the CSV file.
-   `posts.csv`: The output file where the generated posts are stored.
